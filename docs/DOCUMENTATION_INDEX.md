## 📝 Documentation Standards

When creating new documentation:

1. **Keep in Root** - Only active, frequently-referenced guides
2. **Archive Historical** - Move completed phase/session docs to `docs/archive/`
3. **Use Clear Naming** - Format: `CATEGORY_SUBCATEGORY_TYPE.md`
4. **Cross-Link** - Reference related documents
5. **Update Index** - Add new documents to this index
