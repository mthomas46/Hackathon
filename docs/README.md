# Documentation

This directory contains all project documentation organized by category.

## Structure

- `achievements/` - Project achievements and code reduction metrics
- `ci-cd/` - CI/CD pipeline documentation and quality gates
- `cli/` - Command-line interface documentation and guides
- `ecosystem/` - Ecosystem-level documentation and guides
- `migration/` - Migration guides and upgrade documentation
- `project-simulation/` - Project simulation planning and documentation
- `security/` - Security-related documentation and guidelines
- `service-standardization/` - Service standardization plans and guides

## Key Documents

- `CHANGELOG.md` - Project changelog and release notes
- `CONTRIBUTING.md` - Contribution guidelines for developers
