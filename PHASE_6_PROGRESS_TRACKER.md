## **Notes & Decisions**

### **Technical Decisions:**

1. **Hierarchical Retrieval:**
   - Use ChromaDB for vector similarity
   - Redis for caching tier results
   - Token counting via tiktoken

2. **Context Pruning:**
   - Support 4 strategies: relevance, recency, hybrid, importance
   - Use sliding window for recency
   - Combine scores for hybrid

3. **HITL Workflows:**
   - Redis for approval queue
   - PostgreSQL for audit trail
   - WebSocket for real-time updates

4. **Feedback System:**
   - Redis for fast feedback retrieval
   - PostgreSQL for long-term storage
   - Vector embeddings for similarity
