# Orchestrator Integration Tests

This directory contains integration tests specifically for the workflow orchestrator and its coordination capabilities.

## Scripts

### `orchestrator_standalone_simple.py`
**Standalone Orchestrator Runner** - Simple execution environment for testing orchestrator functionality in isolation.

**Features:**
- Standalone orchestrator execution without full ecosystem
- Basic workflow orchestration validation
- Orchestrator configuration testing
- Simple workflow execution monitoring
- Error handling and recovery testing

**Use Cases:**
- Orchestrator development and debugging
- Workflow engine validation
- Orchestrator configuration testing
- Basic workflow execution verification
- Orchestrator isolation testing

### `test_orchestrator_minimal.py`
**Minimal Orchestrator Integration Test** - Basic orchestrator functionality testing with minimal dependencies.

**Features:**
- Minimal orchestrator setup validation
- Core orchestration logic testing
- Basic workflow state management
- Simple service coordination testing
- Orchestrator startup and shutdown validation

**Use Cases:**
- Core orchestrator functionality validation
- Minimal dependency testing scenarios
- Orchestrator startup validation
- Basic workflow coordination testing
- Development environment orchestrator testing

### `test_orchestrator_simple.py`
**Simple Orchestrator Workflow Tests** - Testing of simple orchestrator workflows and basic orchestration scenarios.

**Features:**
- Simple workflow execution validation
- Basic orchestration state management
- Simple service coordination testing
- Workflow completion and error handling
- Orchestrator performance validation

**Use Cases:**
- Simple workflow validation
- Basic orchestration scenario testing
- Orchestrator performance benchmarking
- Workflow execution reliability testing
- Development workflow testing
