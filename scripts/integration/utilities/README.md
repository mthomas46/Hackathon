# Integration Test Utilities

This directory contains utility scripts and benchmarks for integration testing support.

## Scripts

### `benchmark_prompt_store.py`
**Prompt Store Performance Benchmark** - Performance benchmarking and load testing for the prompt store service.

**Features:**
- Prompt store performance benchmarking
- Load testing capabilities
- Response time measurement
- Throughput analysis
- Performance regression detection
- Scalability testing

**Use Cases:**
- Prompt store performance optimization
- Load testing and capacity planning
- Performance regression monitoring
- Scalability assessment
- Benchmarking against performance targets

### `run_sanity_tests.py`
**Integration Sanity Test Runner** - Quick sanity checks for basic integration functionality.

**Features:**
- Basic integration health checks
- Quick validation of core functionality
- Smoke test execution
- Basic connectivity validation
- Rapid feedback for development

**Use Cases:**
- Development environment validation
- Pre-deployment sanity checks
- Quick integration verification
- CI/CD pipeline smoke testing
- Basic functionality regression testing

### `test_interactive_cli.py`
**Interactive CLI Integration Test** - Testing of CLI integration with the broader ecosystem.

**Features:**
- CLI-ecosystem integration validation
- Interactive command testing
- CLI workflow integration
- User interface integration testing
- Command-line ecosystem interaction

**Use Cases:**
- CLI integration validation
- User interface testing
- Command-line workflow testing
- Interactive system validation
- CLI ecosystem communication testing
