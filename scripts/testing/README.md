# Testing Scripts

This directory contains scripts for testing various components and functionality.

## Scripts

- `enhanced_cli_test.py` - Enhanced CLI testing with comprehensive scenarios
- `power_user_cli_test.py` - Power user CLI functionality testing
- `simple_expanded_cli_test.py` - Simple CLI expansion testing
- `test_doc_store_functionality.py` - Document store functionality testing
- `test_doc_store_refactor.py` - Document store refactoring validation

## Purpose

These scripts validate:
- CLI functionality and user experience
- Document store operations and performance
- Refactoring changes and backward compatibility
- Integration testing scenarios
