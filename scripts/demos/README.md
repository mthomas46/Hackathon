# Demo Scripts

This directory contains demonstration scripts that showcase various capabilities of the ecosystem.

## Scripts

- `cli_expansion_demo.py` - Demonstrates CLI expansion and interactive features
- `demo_workflow.py` - Workflow management and execution demonstrations
- `working_power_user_demo.py` - Advanced power user functionality demonstrations

## Purpose

These scripts are used for:
- Demonstrating system capabilities to stakeholders
- Testing complex workflows
- Providing examples for developers
- Validating end-to-end functionality
