# Documentation Scripts

This directory contains scripts for generating documentation and timeline information.

## Scripts

### `generate_living_docs.py`
**Automated Documentation Ecosystem** - Comprehensive living documentation generation from codebase analysis and runtime data.

**Features:**
- Automated API documentation generation from code analysis
- Service architecture documentation with dependency mapping
- Configuration documentation with validation rules
- Performance metrics and health status integration
- Real-time documentation updates from service metadata

**Use Cases:**
- API documentation maintenance and synchronization
- Service architecture documentation for new team members
- Configuration reference generation for deployment teams
- Performance and health documentation for operations
- Automated documentation updates in CI/CD pipelines

### `generate_timeline.py`
**Development Timeline Visualizer** - Interactive timeline generation for project development history and milestones.

**Features:**
- Git commit history analysis and timeline generation
- Milestone and release tracking visualization
- Development velocity and progress metrics
- Interactive timeline exploration and filtering
- Export capabilities for project reporting

**Use Cases:**
- Project progress reporting and stakeholder updates
- Development velocity analysis and planning
- Release planning and milestone tracking
- Historical project documentation and analysis
- Team productivity and contribution visualization

## Usage

```bash
# Generate project timeline
python scripts/docs/generate_timeline.py
```

## Documentation Scope

Documentation scripts focus on:
- ✅ Project timeline and milestone tracking
- ✅ Documentation generation and updates
- ✅ Historical analysis and reporting
- ✅ Project status and progress reporting
