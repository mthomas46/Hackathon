# Ecosystem Scripts

This directory contains scripts for ecosystem-level operations, testing, and analysis.

## Scripts

- `ecosystem_api_audit.py` - Comprehensive API auditing across all services
- `ecosystem_cli_executable.py` - Unified CLI executable for ecosystem management
- `ecosystem_functional_test_suite.py` - End-to-end functional testing suite
- `ecosystem_gap_analysis.py` - Analysis of ecosystem gaps and missing features
- `ecosystem_test.py` - General ecosystem testing utilities
- `ecosystem_unified_test.sh` - Unified testing script for the entire ecosystem

## Purpose

These scripts provide:
- Ecosystem-wide analysis and auditing
- Unified testing and validation
- Gap analysis and feature planning
- Operational management tools
