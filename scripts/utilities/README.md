# Utility Scripts

This directory contains utility scripts for development, maintenance, and operational tasks.

## Scripts

### Development Utilities
- `doc_prompt_store_browser.py` - Browse and manage prompt store documents
- `fix_bare_except.py` - Fix bare except clauses in code
- `fix_imports.py` - Fix and standardize import statements
- `standardize_prompt_store.py` - Standardize prompt store configurations
- `update_docstore_routes.py` - Update document store routing configurations

### Infrastructure Utilities
- `dockerfile_optimization.sh` - Optimize Dockerfiles for performance
- `environment_fix.sh` - Fix environment configuration issues
- `port_conflict_resolution.sh` - Resolve port conflicts in deployments

## Purpose

These scripts automate common development and operational tasks, improving productivity and reducing manual effort.
